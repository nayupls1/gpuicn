shadcn/ui, for gpui.

Beautifully designed components that you copy into your Rust app. You own the code, so read it, tweak it or delete it. One file restyles all of it.

Browse components $ gpuicn add button dialog

Your code, not a dependency

Each component is copied into src/components/ui. Nothing is hidden in a crate you can't change.

Styled from one file

theme.rs holds every color, radius and font, written in oklch so you can paste shadcn themes in directly.

As flexible as shadcn

Builders that implement Styled, so any style you add overrides the defaults like cn() does. Each one works controlled or uncontrolled, and they compose.

Native and fast

Pure gpui: the GPU-accelerated UI framework behind Zed. No webview, no JavaScript.

Every shadcn/ui component, rebuilt for gpui. Click one to see its code. The previews are CSS replicas; run cargo run -p gallery to see the real gpui versions.

Get started

Three steps from cargo new to a finished UI.

1

Install the CLI and set up your crate

cargo install --path crates/gpuicn
cd my-app
gpuicn init

This writes gpuicn.toml, installs theme.rs and utils.rs, and adds mod components; to your crate root.

2

Add the components you need

gpuicn add button card dialog
gpuicn add --all
gpuicn diff button   # what did I change?

Dependencies come along automatically, and so do crate dependencies like unicode-segmentation.

3

Initialize and render

Application::new()
    .with_assets(ui::icon::IconAssets)
    .run(|cx| {
        ui::init(cx);
        // …open your window
    });

// Last child of your root view:
.child(PortalHost::new())

One file to restyle everything

Colors are oklch, exactly like shadcn's CSS variables, so themes from ui.shadcn.com/themes or tweakcn paste straight in. Try the controls below. They change the same tokens theme.rs defines.

The gpuicn CLI
A small tool that copies source files into your crate. Your copies never change unless you run it again.

        

          
gpuicn initCreate gpuicn.toml, install theme + utils, add gpui, wire mod components;. Use --path to pick the folder.

          
gpuicn add <names…>Copy components plus everything they depend on. Takes --all, --overwrite and --dry-run.

          
gpuicn listShow every component and whether it's installed.

          
gpuicn view <name>Print a component's source without installing it.

          
gpuicn diff [name]Show how your copies differ from the registry.

          
gpuicn remove <names…>Delete components, refusing if others still depend on them.

          
--registry <dir>Install from your own registry (registry.toml + ui/*.rs), for example your company's design system.
